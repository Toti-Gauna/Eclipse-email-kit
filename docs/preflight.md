# Preparación de cada propuesta

- Verificar negocio, nombre y notas. Si se afirma un hecho observado, adjuntar fuente pública; si no, apertura sectorial.
- Revisar asunto y preheader en el JSON de salida. El asunto se configura en el proveedor de envío; el HTML por sí solo no lo establece.
- Confirmar remitente y contacto. Mantener un proceso manual para respuestas “No recibir más”.
- Revisar que la demo y las capturas correspondan a funciones publicadas, con distinción de simulación y alcance.
- Definir entregables de la adaptación, gamificación estándar y módulos operativos separados.
- Confirmar oferta, extras excluyentes, landing incluida, anticipo/saldo y una sola mensualidad.
- Verificar promoción concreta: Esencial bonificado; Conectado/IA abonan la diferencia. No tres planes gratis.
- Para pack/gestión económica, confirmar responsable y alcance antes de habilitar salida.
- Publicar assets y condiciones únicamente con autorización posterior; completar URLs públicas HTTPS y comprobarlas.
- Para versión breve, verificar presentación completa pública. No incluir datos personales en la URL de galería.
- Trailer opcional: ambos recursos verificados o módulo omitido de envío. Sin enlaces falsos.
- Ejecutar build, validate y revisar móvil, fallback y sin imágenes. Probar Gmail/Outlook reales cuando haya acceso autorizado, sin enviar emails sin instrucción.
- Exportar con `--mode send`. La salida no constituye autorización de envío.
